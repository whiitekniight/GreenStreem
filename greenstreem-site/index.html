GreenStreem Recorder — preview 0.2.0

Your own Windows or Linux computer records while your phone, tablet or TV app is off. Save to an existing local, USB or accessible NAS folder. Use Android app 1.9.73 or newer for weekly schedules and the combined recordings list.

Hold a guide program for Record now, Schedule recording or Stop / cancel. Choose weekly repeats and 0–30 extra minutes before and after (three minutes each by default). Weekly repeats record the same channel and local time slot, even if the program title changes.

Keep the recorder computer on, signed in and running, with its storage connected. Turn off your Android device only after the recorder confirms the schedule. One MPEG-TS recording at a time is supported. Device-only recording remains available.

Windows Recorder — preview 0.2.0

Download Windows Recorder ZIP
  1. Close the old recorder when it has no recording in progress. Extract the entire ZIP to a folder on your Windows PC, then open GreenStreem Recorder.exe. Keep all files from the ZIP together.
  2. Choose an existing recording folder. For a NAS, open its shared folder in File Explorer and sign in first.
  3. In GreenStreem, open Recordings → Set up PC recorder → Find my PC recorder. If already connected, keep that connection.
  4. For a new connection, click Connect a device on the computer and enter its code in the app.
  5. Schedule a program and wait for confirmation. Open Recordings in the app to replay or manage computer recordings directly — no separate shared-folder setup is needed.

Minimize the recorder to keep it running. Your existing recorder folder, device connections and schedules are retained when updating. Setup notes are included in the ZIP.

Linux Recorder — preview 0.2.0

Download Linux Recorder
  1. Extract the archive. Requires Python 3.10 or newer, Tk and venv. On Ubuntu/Debian, install python3-tk and python3-venv if needed.
  2. Open a terminal in the extracted folder and run sh start-recorder.sh. It prepares the app and opens the GreenStreem recorder window.
  3. Choose an existing local or USB folder, or a NAS share already mounted in your Linux file manager.
  4. Connect from Android using the same steps as Windows. Computer recordings appear directly in the app’s Recordings list.

Keep Linux awake; disable automatic sleep for scheduled recording. Optional desktop sign-in startup is available in the recorder. Headless setup instructions are included in the archive.
